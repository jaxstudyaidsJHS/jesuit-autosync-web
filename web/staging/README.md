# Off-air web staging placeholder

This static page is a **safe placeholder** for a future separately deployed Netlify staging website. It contains **no Firebase configuration**, scoring controls, remote endpoints, or tracking SDKs.

This folder is deliberately NOT connected to the existing production Netlify project. When staging is needed, create a **separate Netlify site** with publish directory `web/staging`, review the project permissions, and require separate staging Firebase credentials.

Do not connect this repository directly to the current Netlify production site until the migration/security review passes.
